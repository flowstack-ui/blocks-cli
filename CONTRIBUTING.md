# Contributing

Thanks for helping improve the FLOWSTACK Blocks CLI.

Search existing issues before using the structured bug or feature forms.
Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
Never attach licensed block source, credentials, or private application code
to a public issue or pull request.

Keep pull requests focused on the public CLI. Preserve authentication, registry,
path-safety, and copy-installation boundaries. Follow the repository's local
guidance and verification commands, and update tests, documentation, and the
changelog when public behavior changes.

By participating, you agree to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
