# Security Policy

## Supported versions

Security fixes are made for the latest published Blocks CLI.

## Report a vulnerability

Do not open a public issue. Submit a
[private security advisory](https://github.com/flowstack-ui/blocks-cli/security/advisories/new)
with the affected version and command, impact, realistic attack scenario,
minimal reproduction, environment, and suggested remediation. Remove
credentials, registry tokens, licensed block contents, private application
source, and unrelated user data.

In scope are registry and download verification, authentication boundaries,
path handling, unsafe overwrites, command execution, dependency installation,
and generated-file handling. The private paid catalog, consumer modifications,
third-party package managers or registries, and scanner-only findings without
credible impact are generally out of scope for this repository.
